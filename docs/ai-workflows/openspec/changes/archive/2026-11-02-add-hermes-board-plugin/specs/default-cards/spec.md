# 能力规格：首次初始化与默认卡片

状态：已确认（2026-10-31 16:10 用户指示进入计划阶段）。初始卡片和天气默认城市对应 [proposal.md](../../proposal.md) 确认记录第 7 项，布局表见 [design.md](../../design.md) 第 14 节。

## ADDED Requirements

### Requirement: 幂等的首次初始化
系统 MUST 在第一次调用 API 或工具时，在进程间文件锁的保护下检查 `board.json`。不存在时，从插件内置的 `cards/` 安装 8 张默认卡片，写入默认布局，对账 cron，并运行 `runOnInstall` 脚本。多个进程同时触发时 MUST 只初始化一次。之后插件升级 MUST NOT 覆盖已有卡片，用户可以用 `restore_default` 恢复某张默认卡片。

#### Scenario: 两个进程同时首次访问
- **GIVEN** `hermes serve` 和一个 CLI 会话同时第一次加载插件。
- **WHEN** 两边都触发初始化。
- **THEN** 只有一方完成安装，另一方等待后直接使用结果；cron 任务不会重复。

#### Scenario: 用户改过默认卡片后升级插件
- **GIVEN** 用户已让 Agent 修改了天气卡片。
- **WHEN** 插件升级到包含新版默认天气卡片的版本。
- **THEN** 用户修改过的卡片保持不变。

### Requirement: 默认布局无缝铺满
系统 MUST 用 design.md 第 14 节的默认布局，让 8 张卡片恰好铺满 24×16 网格，没有空洞也没有重叠：天气 8×8 @ (0,0)；时钟 8×4 @ (8,0)；世界时钟 4×4 @ (8,4)；倒数日 4×4 @ (12,4)；日历 8×8 @ (16,0)；番茄钟 8×8 @ (0,8)；便签 8×8 @ (8,8)；待办 8×8 @ (16,8)。

#### Scenario: 首次打开
- **WHEN** 用户第一次打开看板。
- **THEN** 8 张卡片无缝铺满 24×16 网格，覆盖率为 100%；在约 1280×800 的窗口下基本是一整屏。

### Requirement: 天气卡片
系统 MUST 提供天气卡片：脚本通过 Open-Meteo 地理编码和预报接口（无需密钥）每 30 分钟获取一次数据，安装后立即运行一次；城市存在卡片状态 `city` 中，默认为“北京”。卡片 MUST 显示当前温度、天气现象（中文）、最高和最低温，8×8 尺寸下还要显示未来 3 天预报；用户可以在卡片里修改城市并立即刷新；获取失败时显示上次数据和“更新于 …”。

#### Scenario: 修改城市
- **WHEN** 用户在天气卡片中把城市改为“上海”并确认。
- **THEN** 卡片状态更新，刷新脚本立即运行，卡片显示上海的天气，之后的 cron 也使用上海。

### Requirement: 时间类卡片
系统 MUST 提供：时钟卡片（使用 Desktop 本机时间，显示时、分、秒、日期和星期）；世界时钟卡片（使用 Intl 时区，默认纽约、伦敦、东京，可以编辑）；日历卡片（月历，高亮今天，可以前后翻月）；倒数日卡片（目标日期和名称可以编辑，默认“元旦”，显示剩余天数）。这些卡片都不需要远程脚本。

#### Scenario: 跨天
- **GIVEN** 看板一直开着。
- **WHEN** 本机时间跨过零点。
- **THEN** 时钟、日历和倒数日都自动更新到新的一天，不需要刷新页面。

### Requirement: 番茄钟
系统 MUST 提供番茄钟卡片：默认专注 25 分钟、休息 5 分钟，支持开始、暂停、重置、跳过。阶段和起止时间戳保存在卡片状态里，刷新页面或切换设备后能恢复正确的剩余时间；每个阶段结束时通过 `ui.remind` 提醒。

#### Scenario: 刷新页面后恢复
- **GIVEN** 专注已经进行了 10 分钟。
- **WHEN** 用户重新加载看板。
- **THEN** 番茄钟显示剩余约 15 分钟，并继续倒计时。

### Requirement: 记录类卡片
系统 MUST 提供：便签卡片（多行文本，停止输入 800ms 后自动保存到卡片状态）；待办卡片（新增、勾选、删除，保存在卡片状态里）。这两类内容保存在远程，任何连接同一 profile 的 Desktop 都能看到。

#### Scenario: 在另一台 Desktop 打开
- **GIVEN** 用户在 A 机的便签里写了内容。
- **WHEN** 用户在连接同一远程 profile 的 B 机上打开看板。
- **THEN** 看到相同的便签内容。

### Requirement: 默认卡片遵循卡片标准
所有默认卡片 MUST 通过校验器，没有错误；MUST 只使用设计令牌和组件类；MUST 在声明的每一种尺寸下都不出现整体滚动条，并且适配浅色和深色模式。默认卡片同时作为技能模板的参考实现。

#### Scenario: 校验默认卡片
- **WHEN** 在测试中对 `cards/` 下的每个默认卡片包运行校验器。
- **THEN** 全部没有错误，也没有设计类警告。
