# 变更提案：卡片悬浮操作、天气横幅与默认卡片全屏适配

## 背景

当前每张正常卡片的全屏按钮始终显示在右上角，会遮挡天气、日历、世界时钟、倒数日等默认卡片自身的头部操作。按钮也缺少紧邻的快捷移除入口。虽然宿主已经能用同一份卡片 HTML 打开全屏实例，但八张默认卡片尚未把 `fullscreen` 当作独立展示尺寸进行布局适配，天气卡片也尚未声明已经合法的 `12x4` 横幅尺寸。

## 目标

- 将右上角宿主操作收敛为悬浮操作组：全屏在左，“删除”在右，仅在卡片 hover 或键盘焦点进入时显示。
- “删除”按现有安全语义从看板移除卡片，不删除卡片包、状态或数据，并允许之后重新添加。
- 为默认卡片预留宿主操作安全区，避免操作组遮挡卡片自身的头部按钮或内容。
- 天气卡片新增 `12x4` 可选尺寸，并提供与该横幅比例匹配的布局。
- 八张默认卡片都使用各自唯一的 `index.html` 同时渲染网格与全屏，通过运行时尺寸环境自适应，不维护独立的全屏 HTML。

## 非目标

- 不提供一键彻底删除卡片包的右上角按钮。
- 不改变全局尺寸预设、看板网格列数或默认布局中天气的初始尺寸。
- 不为第三方卡片强制重写内部布局；宿主操作仍应有稳定定位，默认卡片负责完整的安全区和全屏适配示范。
- 不改用浏览器或操作系统原生 Fullscreen API。

## 成功标准

- 静止状态下右上角不显示宿主操作；hover 或 `focus-within` 时同时出现全屏与删除按钮，离开后隐藏。
- 操作组顺序固定为全屏在左、删除在右，鼠标与键盘均可操作，焦点样式和可访问名称明确。
- 八张默认卡片在全部已声明网格尺寸下，头部操作均不被宿主操作组遮挡。
- 点击删除后卡片从布局消失，但仍能从“添加卡片”恢复，原状态与数据保留。
- 天气清单接受 `12x4`，该尺寸下当前天气、未来三天和必要操作无溢出、遮挡或裁切。
- 八张默认卡片在全屏弹窗中继续读取和修改同一份数据，且均由原 `index.html` 渲染；窗口改变大小后内容重新排布，无明显拉伸、超出或大面积无意义留白。
