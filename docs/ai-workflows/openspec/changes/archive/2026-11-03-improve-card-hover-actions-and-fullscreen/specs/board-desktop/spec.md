# 看板桌面端增量规格

## 卡片悬浮操作组

系统 MUST 为每张状态正常且位于看板中的卡片提供右上角宿主操作组。操作组 MUST 按从左到右顺序包含“全屏查看”和“删除”两个按钮；删除 MUST 仅从当前看板移除卡片，不得删除卡片包、卡片状态或数据。

操作组 MUST 在卡片默认静止状态下不可见且不可命中，只在卡片 hover 或焦点位于卡片内时可见并可命中。两个按钮 MUST 可通过键盘访问，具有包含动作和卡片标题的可访问名称，并且在显示、隐藏或获得焦点时不得触发卡片拖动或缩放。

### 场景：鼠标悬浮后显示两个操作

- **GIVEN** 一张状态正常的卡片当前没有焦点，鼠标也不在卡片上。
- **THEN** 右上角全屏和删除按钮均不可见、不可点击。
- **WHEN** 鼠标进入卡片。
- **THEN** 全屏按钮显示在左，删除按钮显示在右。
- **WHEN** 鼠标离开卡片且操作组内没有焦点。
- **THEN** 两个按钮再次隐藏。

### 场景：键盘用户访问隐藏操作

- **GIVEN** 用户通过键盘把焦点移入卡片。
- **THEN** 操作组显示，两个按钮可按顺序聚焦，焦点轮廓清晰。
- **WHEN** 焦点离开卡片。
- **THEN** 操作组隐藏。

### 场景：快捷删除可恢复

- **GIVEN** 卡片存在远程状态、数据或定时任务。
- **WHEN** 用户点击右上角删除按钮且布局提交成功。
- **THEN** 卡片从当前看板消失，其定时任务暂停。
- **AND** 卡片包、状态和数据保持不变，该卡片仍出现在“添加卡片”列表中。

## 宿主操作安全区

系统 MUST 让所有默认卡片在其声明的每种非全屏尺寸下避开右上角宿主操作组。卡片自身的可见按钮、输入框、标题关键信息和状态提示 MUST NOT 位于宿主操作组的命中矩形下方。

### 场景：带头部按钮的卡片显示宿主操作

- **GIVEN** 天气、日历、世界时钟或倒数日卡片以任一已声明尺寸显示。
- **WHEN** 用户 hover 卡片使宿主操作组出现。
- **THEN** 卡片自身的头部按钮仍完整可见并可点击。
- **AND** 宿主按钮与卡片自身按钮的命中区域不重叠。

## 单文档全屏响应

系统 MUST 让全屏实例加载与网格实例相同的卡片 entry 文档，并以 `fullscreen` 逻辑尺寸和当前弹窗主体 pixel 尺寸驱动文档自适应。系统 MUST NOT 要求或读取独立的全屏 HTML 入口。

全屏主体尺寸变化时，系统 MUST 向现有文档发送 resize 环境更新，不得仅因 resize 重新加载 iframe。卡片的当前交互状态、编辑焦点以及与远程状态/数据的连接 MUST 保持有效。

### 场景：调整全屏弹窗大小

- **GIVEN** 用户已在默认卡片的全屏实例中开始编辑或操作。
- **WHEN** 全屏主体的宽度或高度改变。
- **THEN** 同一 iframe 文档根据新的 pixel 尺寸重新排版。
- **AND** 文档不重新加载，当前编辑焦点和未提交交互不丢失。
