# 变更提案：卡片布局稳定性、横幅尺寸与全屏查看

## 背景

当前自动整理会同时改变看板高度和多张卡片的位置。在滚动条槽位随内容高度变化、卡片继续执行几何过渡时，可能触发布局宽度反复变化，表现为卡片持续抖动。全局尺寸也缺少 12×4 与 24×4 两种横幅规格，且卡片没有独立的全屏查看入口。

## 目标

- 自动整理只产生一次稳定的布局结果，整理期间不出现反复缩放或位置抖动。
- 将 `12x4`、`24x4` 加入全局合法尺寸，卡片包可按需声明。
- 每张可用卡片右上角提供放大按钮，以应用内模态弹窗全屏查看。
- 全屏仅影响当前显示，不写入看板布局；关闭后恢复原看板状态。

## 非目标

- 不调用操作系统或浏览器原生 Fullscreen API。
- 不自动为所有既有卡片增加新尺寸声明。
- 不在 v1 中增加“固定至桌面”等弹窗附加功能。

## 成功标准

- 自动整理前后滚动条占位稳定，提交期间卡片不执行几何过渡。
- 后端校验、前端吸附与文档均接受两个新尺寸。
- 可通过右上角按钮打开和关闭全屏弹窗；弹窗中的卡片可继续读取数据、执行操作和响应主题/数据变化。
- 新增行为有自动测试，桌面包可重新构建并通过一致性检查。
