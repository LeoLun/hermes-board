# 变更提案：移除看板页头并迁移到 Claude 卡片风格

- 变更标识：`claude-card-style-and-header`
- 日期：2026-11-03
- 状态：已实施并归档（2026-11-03）
- 视觉基准：[Claude DESIGN.md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/claude/DESIGN.md)

## 为什么做

看板页面把“添加卡片”和刷新按钮投射到 Desktop 页头。宿主用激活状态的 `PaneTab` 承载该区域，因此显示蓝色下划线，容易被误认为可切换的 Tab。用户要求移除这个页头。

当前卡片设计系统基于 Apple DESIGN.md，用户要求将 8 张默认卡片和之后由 Agent 生成的卡片统一迁移到 Claude 的暖色、编辑感设计语言。

## 方案比较与选择

| 方案 | 收益 | 代价 | 结论 |
|---|---|---|---|
| A. 只改 8 张默认卡片的内联样式 | 短期观感可控 | 新生成卡片仍是旧风格，且重复样式多 | 不选 |
| B. 迁移运行时全局令牌/组件，同步生成技能、参考文档与模板，并审计默认卡片 | 默认卡片和未来卡片共用一个真实来源，改动最小 | 需重建 Desktop bundle 并补充设计回归测试 | **选择** |
| C. 引入可切换的 Apple/Claude 两套主题 | 保留旧外观 | 新增配置、兼容与测试成本，超出用户要求 | 不选 |

## 范围

### 包含

- 移除看板页的 `WorkspacePageHeaderControl` 及其“添加卡片/刷新”页头内容。
- 保留添加卡片与刷新能力的非页头入口：命令面板和空看板内联操作。
- 将卡片运行时令牌与公共组件迁移到 Claude 暖色设计系统。
- 更新 8 张默认卡片与基础模板中必要的局部样式，使其符合新令牌和字体层级。
- 更新 `card-author` 技能及设计参考，使新生成卡片默认遵循 Claude 风格。
- 补充自动化测试，检查页头已移除且关键 Claude 令牌已生效。

### 不包含

- 修改 Hermes Desktop 宿主的 `PaneTab` 实现。
- 加载 Copernicus、Tiempos Headline 或 StyreneB 等受限字体文件；仅使用文档建议的系统回退栈。
- 把 Claude 商标或 Anthropic 标志引入卡片。
- 改变卡片数据、脚本、布局 DSL 或调度行为。

## 成功标准

1. 打开看板时不再显示“添加卡片/刷新”页头及蓝色 Tab 下划线。
2. 8 张默认卡片共享暖奶油画布、珊瑚强调色、暖黑文字、克制边框和 8/12px 圆角，深色模式保持可读。
3. `card-author` 设计参考和基础模板不再声称基于 Apple，明确 Claude 的颜色、字体、形状、间距和禁用项。
4. 默认卡片和模板仍通过严格校验，JS 测试、相关 Python 测试、打包与 bundle 一致性检查通过。
