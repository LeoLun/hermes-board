# 看板 Desktop 增量规格

## 页头

系统 MUST NOT 为 `/hermes-board` 页面注册 `WorkspacePageHeaderControl` 或其他页头内容。因此宿主 MUST NOT 因看板插件显示伪似激活 Tab 的蓝色下划线。

### 场景：打开有卡片的看板

- **WHEN** 用户进入 `/hermes-board`。
- **THEN** 看板内容直接占据页面区域。
- **AND** 顶部不出现“添加卡片”和刷新控件。

## 能力可达性

移除页头后，系统 MUST 保留“添加卡片”和“重新加载”的可用入口。

### 场景：空看板

- **WHEN** 看板没有任何已放置卡片。
- **THEN** 空状态 MUST 提供可点击的“添加卡片”操作。

### 场景：重新加载

- **WHEN** 用户从命令面板执行“看板：重新加载”。
- **THEN** 系统 MUST 重新加载看板和卡片数据。
